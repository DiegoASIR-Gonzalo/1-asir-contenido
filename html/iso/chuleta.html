La shell sintaxis: variables, cadenas y bucles

  • var=valor asigna; $var la usa (sin espacios alrededor de =).
  • comando1 ; comando2 ejecuta los dos siempre.
  • comando1 && comando2 el segundo solo si el primero funcionó.
  • comando1 || comando2 el segundo solo si el primero falló.
  • {a..z} y {1..9} generan listas; fich$i.txt combina bucle y nombre.
  • * = todo, ? = un carácter, [uo]* = empieza por u o por o.
  • "…" respeta $var; '…' no lo expande.
$ for i in {a..z}; do touch fich$i.txt; done
$ for i in {A..Z}; do for j in {0..9}; do mv $i$j.txt ../destino/; done; done
$ mkdir prueba && cp documento.txt prueba/

Redirecciones y tuberías adónde va la salida

  • > salida a fichero (sobrescribe). >> añade al final.
  • 2> solo errores. 2>> añade errores.
  • 2>&1 errores hacia donde vaya la salida. &> salida+errores juntas.
  • < entrada desde fichero. <<FIN here-document hasta la línea FIN.
  • /dev/null agujero negro: todo lo que escribas ahí desaparece.
  • | tubería: la salida de un comando entra en el siguiente.
  • tee fichero muestra por pantalla y guarda en el fichero (-a añade, no sobrescribe).
$ ls -l > lista.txt
$ find /noexiste -type d 2> malos
$ who | sort > persona
$ cat <<EOF > mensaje.txt
hola
EOF
$ find /etc -type f | tee ficheros.txt | wc -l

7z empaqueta y comprime (7-Zip)

7z [a|x] [-oCARPETA] fichero.7z [archivos…]

  • a añadir (comprimir). x extraer conservando la estructura de carpetas.
  • -oCARPETA carpeta de destino al extraer (pegada a la -o, sin espacio).
$ 7z a comprimido.7z documento.txt
$ 7z x comprimido.7z -odescompresion/

alias / unalias apodos para comandos

alias [nombre='comando'] · unalias nombre

  • Sin argumentos lista los alias actuales.
  • unalias -a borra todos.
  • Solo dura mientras la terminal esté abierta.
$ alias ll='ls -l'
$ ll
$ unalias ll

basename quita las carpetas a una ruta

bzip2 / bunzip2 comprime ficheros de uno en uno · .bz2

bzip2 [opciones] fichero · bunzip2 fichero.bz2

  • Solo ficheros individuales (para carpetas, usa tar).
  • -k conserva el fichero original al comprimir.
  • -d descomprimir (equivale a usar bunzip2).
  • -1…-9 nivel de compresión (9 = máxima, más lenta).
  • Comprime más que gzip pero más despacio.
$ bzip2 documento.txt        # queda documento.txt.bz2
$ bzip2 -k documento.txt     # lo comprime sin borrar el original
$ bunzip2 documento.txt.bz2

cat muestra o une ficheros

cat [opciones] fichero…

cd cambia de carpeta

cd [ruta]

  • cd .. sube una carpeta. cd o cd ~ va a tu home.
  • cd - vuelve a la carpeta anterior.
  • Ruta absoluta empieza por /; relativa desde donde estás.
$ cd dir3; cd enlacedir1   # entrar por un enlace simbólico

chmod cambia permisos

chmod [-R] modo fichero…

  • Simbólico: quién (u dueño, g grupo, o otros, a todos) + +-= + rwx. Ejemplos: a-w, u+w, u=rwx,go=rx.
  • Octal: 3 cifras, cada una suma 4 (lectura) + 2 (escritura) + 1 (ejecución).
  • -R recursivo (a toda la carpeta y sus hijos).
  • En un directorio, la x es «permiso de paso» para atravesarlo.
$ chmod 666 fich1
$ chmod a-w dir2
$ chmod u=rwx,go=rx dir2
$ chmod -R 600 privada/

compress / uncompress compresor antiguo de UNIX · .Z

compress fichero · uncompress fichero.Z

  • Solo ficheros individuales. Hoy casi no se usa.
  • En tar: opción -Z → .tar.Z.

cp copia ficheros

cp [-r] [-i] [-u] origen… destino

  • -r copia carpetas enteras (recursivo).
  • -i pregunta antes de sobrescribir.
  • -u solo copia si el origen es más nuevo que el destino.
  • -- fin de opciones (para ficheros que empiezan por guion).
$ cp /bin/u* nuevo1/
$ cp dir1/fich1 dir2/enlace
$ cp -r carpeta1 /backup/

cut corta campos o columnas de cada línea

cut -d separador -f campos fichero

  • -d : carácter separador.
  • -f 1 campo 1; -f 1,7 varios; -f 1-3 un rango.
  • -c 1-10 por posición de caracteres.
$ cut -d : -f 1 /etc/passwd
$ cut -d : -f 1,7 /etc/passwd
$ cut -d : -f 1 /etc/passwd | wc -l

date fecha y hora

date [+formato] · date -d fecha

  • +%F 2026-11-11 · +%Y año · +%m mes · +%d día
  • +%H·+%M·+%S hora, minutos, segundos
  • +%A día de la semana (por extenso) · +%B nombre del mes · %% un % literal
  • -d fechas relativas: "tomorrow", "yesterday", "next monday", "2 days ago", "2026-12-31".
$ date +%F
$ date -d tomorrow +%A
$ date -d "next friday"

du cuánto ocupa cada carpeta

du [-h] [-s] [-a] [ruta]

echo [-e] texto

$ echo "hola" > saludo.txt

file de qué tipo es un fichero

file fichero…

$ file /home/usuario/.bashrc

find busca ficheros y directorios

find ruta [-type t] [-name patrón] [-user usuario] [-empty] [-newermt fecha] [-exec cmd {} \;]

  • -type f ficheros · -type d directorios.
  • -name "*.h" por nombre (con comodines, entre comillas).
  • -user root por propietario.
  • -empty vacíos. -newermt "yesterday" modificados desde esa fecha.
  • -exec comando {} \; ejecuta por cada resultado. {} + agrupa muchos.
  • -ls muestra los detalles como ls -l.
  • -print0 separa con byte nulo → combinar con xargs -0.
$ find /usr/bin -type f
$ find / -type f -user root
$ find /usr/include -name "*.h"
$ find . -type f -name "*.jpg" -exec rm -f {} \;
$ find ~ -type d > direc

grep filtra las líneas que coinciden

grep [-i] [-n] [-v] [-c] patrón [fichero]

  • -i ignora mayúsculas y minúsculas.
  • -n numera las líneas que coinciden. -v las que NO coinciden.
  • -c cuenta cuántas coinciden.
  • Patrones: ^l empieza por l · x$ acaba en x · "ai" contiene ai.
$ grep -i "^l" texto
$ grep -i "^l" texto | wc -l
$ grep "/bin/bash" /etc/passwd | wc -l

gzip / gunzip comprime ficheros de uno en uno · .gz

gzip [opciones] fichero · gunzip fichero.gz

  • Solo ficheros individuales. Para carpetas: tar -czvf.
  • -k conserva el original. -d descomprimir (igual que gunzip).
  • -1…-9 nivel de compresión.
  • Rápido; con ficheros pequeños puede ocupar más que el original.
$ gzip documento.txt        # queda documento.txt.gz
$ gzip -k documento.txt
$ gunzip documento.txt.gz
$ tar -czvf copia.tar.gz documentos/

head el principio de un fichero

head [-n N] [fichero]

  • Por defecto las primeras 10 líneas.
  • -n 3 exactamente 3.

$ head -n 3 /etc/passwd
$ ls | head -n 5

ln enlaces duros y simbólicos

ln [-s] destino nombre_enlace

  • Sin -s: enlace duro, otro nombre para el mismo contenido e inodo. Si borras el original, el enlace sigue funcionando.
  • -s: enlace simbólico, un acceso directo que guarda la ruta. Si borras el original, queda roto.
  • ls -l muestra los simbólicos con l y nombre -> destino.
$ ln -s dir1 dir3/enlacedir1
$ ln prueba/dir1/fich1 prueba/dir1/enlace
$ ln -s prueba/dir2/enlace prueba/dir1/enlafich1

locate / updatedb busca por nombre en la base de datos

locate patrón · updatedb

  • Mucho más rápido que find, pero solo ve lo que updatedb haya indexado.

ls lista el contenido

ls [-l] [-a] [-R] [-d] [-h] [-i] [-r] [-t] [-S] [ruta…]

  • -l formato largo: tipo+permisos, enlaces, dueño, grupo, tamaño, fecha, nombre.
  • -a incluye los ocultos (los que empiezan por .).
  • -R recursivo (todas las subcarpetas). -d la carpeta en sí, no su contenido.
  • -h tamaños legibles. -i número de inodo. -r orden inverso.
  • -t por fecha. -S por tamaño.
  • Primera letra del formato largo: d directorio, l enlace, p tubería, - fichero.
$ ls -l
$ ls -ld prueba/dir2
$ ls -l /bin/u*
$ ls -l /dev/tt*

mkdir crea carpetas

mkdir [-p] [-m modo] carpeta…

  • -p crea las carpetas padre si faltan (rutas anidadas de golpe).

$ mkdir dir1 dir2 dir3

mkfifo crea una tubería con nombre

mkfifo [-m modo] nombre…

  • Es un fichero especial (p en ls -l) por el que pasan datos de un proceso a otro.
  • Escribes con > y lees con cat; al leerlo se vacía.
$ mkfifo tuberia

rm borra ficheros

rm [-r] [-i] [-f] fichero…

  • -r borra carpetas con todo su contenido.

  • ¡No hay papelera! Lo borrado no se recupera.

sort ordena líneas

sort [-n] [-r] [-k campo] [-t sep] [fichero]

  • -n numérico. -r inverso (Z→A).
  • -k 2 ordena por el campo 2. -t : separador para los campos.
$ who | sort > persona

tail el final de un fichero

tar empaqueta y comprime carpetas enteras

tar [-c|-t|-x] [-v] [-f fichero] [-z|-j|-J|-Z] [-C carpeta] [--exclude=patrón] [archivos…]

  • -c crear · -t listar contenido sin extraer · -x extraer.
  • -v verboso (muestra lo que procesa) · -f nombre del fichero tar.
  • -z gzip (.tar.gz) · -j bzip2 (.tar.bz2) · -J xz (.tar.xz) · -Z compress (.tar.Z).
  • -r añade ficheros a un tar sin comprimir; a un .tar.gz no se puede: primero descomprime, añade y vuelve a comprimir.
  • -C carpeta extraer dentro de esa carpeta (hay que crearla antes).
  • --exclude='ruta' excluye ficheros al crear (se puede repetir; no elimina lo que ya estaba dentro).

Crear y listar

$ tar -cvf comprimido.tar archivos/          # solo empaqueta
$ tar -czvf copia.tar.gz documentos/          # empaqueta y comprime con gzip
$ tar -tvf comprimido.tar                     # ¿qué hay dentro?
$ tar -tzvf comprimido.tar.gz                 # listar, con detalles

Extraer

$ mkdir descompresion
$ tar -xvf comprimido.tar -C descompresion/
$ tar -xzvf comprimido.tar.gz -C descompresion/ archivos/documento1.txt
$ tar -xzvf comprimido.tar.gz -C descompresion/ archivos/documento1.txt archivos/documento2.odt
$ tar -xzvf comprimido.tar.gz -C descompresion/ archivos/   # un directorio completo

Añadir y excluir

$ tar -rvf comprimido.tar archivos/nuevo_archivo.txt
$ tar --exclude='archivos/documento3.pdf' -cvf sin_pdf.tar archivos/
$ gunzip comprimido.tar.gz && tar -rvf comprimido.tar nuevo.txt && gzip comprimido.tar

Extensiones según la compresión

ExtensiónSignificado
.tarempaquetado, sin comprimir
.tar.gzcomprimido con gzip (-z)
.tar.bz2comprimido con bzip2 (-j)
.tar.xzcomprimido con xz (-J)
.tar.zstcomprimido con zstd (--zstd)
.tar.Zcomprimido con compress (-Z)

Solo tar: agrupa, no comprime. Con gzip suele ser el más rápido; xz comprime más en ficheros grandes pero tarda más.

umask permisos por defecto

umask [máscara]

  • Sin opciones muestra la máscara actual (normalmente 022).
  • Se resta de 666 en ficheros y de 777 en carpetas: con 022 → ficheros 644, carpetas 755.

$ touch uno; ls -l uno

xz / unxz compresión máxima · .xz

xz [opciones] fichero · unxz fichero.xz

  • Solo ficheros individuales. Ratio altísimo, pero lento.
  • -k conserva el original. -d descomprimir. -0…-9 nivel.
  • En tar: -J → .tar.xz.
$ xz documento.txt
$ unxz documento.txt.xz
$ tar -cJvf copia.tar.xz documentos/

zip / unzip comprime ficheros y carpetas

zip [-r] fichero.zip [archivos…] · unzip fichero.zip [-d carpeta]

  • -r recursivo: carpetas y subcarpetas enteras (a diferencia de gzip/bzip2/xz).
  • unzip -d carpeta extrae dentro de esa carpeta.
$ zip -r comprimido.zip carpeta/
$ unzip comprimido.zip
$ unzip comprimido.zip -d descompresion/

Atajos de teclado en cualquier Linux

  • Tab completa nombres y comandos (doble Tab lista opciones).
  • ↑ ↓ recorren el historial.
  • Ctrl+L limpia la pantalla (el historial sigue ahí).
  • Ctrl+C cancela el comando en marcha.
  • Ctrl+A / Ctrl+E cursor al principio / al final.
  • Ctrl+U borra desde el cursor hasta el principio.
  • Ctrl+W borra la palabra anterior.
  • Ctrl+R busca hacia atrás en el historial.
  • Alt+. inserta el último argumento del comando anterior.
  • Ctrl+X+E abre el comando en nano para editarlo.
